# Customer Relationship Management (CRM) System

A web-based Customer Relationship Management system developed using Python Flask and SQLite.

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Visual Studio Code

## Features

- Add customer records
- View customer records
- Update customer information
- Delete customer records
- Store customer data using SQLite
- Simple and user-friendly web interface

## Project Description

This project was developed as an academic project to manage customer information efficiently through a centralized web-based system.
